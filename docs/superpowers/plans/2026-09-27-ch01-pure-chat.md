# Ch01 纯对话链路实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 电商智能客服系统 ch01 纯对话端到端跑通：SSE 逐 token 多轮对话、PromptTemplate 模板化、with_structured_output 售后抽取、token 预算历史裁剪。

**Architecture:** 分层单体（方案 A）：`api/`（路由 + SSE 格式化）→ `services/`（会话内存、裁剪、抽取）→ `llm/`（模型工厂）← `core/`（.env 配置）；`prompts/` 模板文件 + loader；`schemas/` Pydantic。历史存进程内存 dict，无 DB / 无 Agent / 无页面。

**Tech Stack:** Python（uv 管理与钉版）、FastAPI（原生 `fastapi.sse`）、`langchain[openai]`、`pydantic-settings`、pytest + pytest-asyncio + httpx。

**Spec:** `docs/superpowers/specs/2026-09-27-ch01-pure-chat-design.md`（计划与 spec 冲突时以 spec 为准）

## Global Constraints

- 统一 OpenAI 协议：`init_chat_model(model_provider="openai", base_url=…, api_key=…)`（spec §7.2）
- 默认 DeepSeek：`LLM_BASE_URL=https://api.deepseek.com/v1`、`LLM_MODEL=deepseek-chat`（spec §3）
- 六类枚举（verbatim）：退货退款 / 换货 / 维修 / 物流问题 / 发票售后 / 其他（spec §7.5）
- SSE：OpenAI 兼容 delta 行 + `data: [DONE]` 结束；流内错误先发 `{"error":{"message":…}}` 再 `[DONE]`（spec §5.1）
- `.env` 字段名固定：`LLM_PROVIDER / LLM_BASE_URL / LLM_MODEL / LLM_API_KEY / HISTORY_TOKEN_BUDGET(=3000) / REQUEST_TIMEOUT(=60)`（spec §7.1）
- 无工具调用、无 Agent 循环、无 DB、无聊天页面（spec §2）
- TDD 铁律：可单测单元必须先写失败测试并亲眼看它失败；纯 Prompt/数据产出用评估集验证（阈值 complaint_type=100%、order_no≥90%、expected_solution≥80%，spec §8.2）
- 库 API 用法先 Context7 核对再写（2026-09-27 已核：fastapi.sse / init_chat_model / with_structured_output(include_raw=True) / astream 聚合；实现中遇新 API 先查）
- Python 版本：uv 先试 3.14；依赖不兼容则 `.python-version` 钉 3.12，就地处理（spec §11）
- 分支：`ch01/pure-chat`，禁止直接提交 main；合并走 finishing-a-development-branch
- `.env` 不入库；文件一律 LF（`.gitattributes` 已钉）
- 每个任务完成后在 `dev-notes/ch01.md` 追记一段（用户关键原话 / 关键产出 / 拒绝纠偏 / 翻车返工）
- **Key 未配置**：Task 3 冒烟、Task 9 跑分、Task 10 真验收为 live 步骤——单测与 fake 驱动部分先行；到 live 步骤若 `.env` 无 key，ledger 记 `Deferred(key)` 继续后续任务，key 配好后回来补跑

## Review Focus

1. **空会话首轮**：无历史时裁剪器不得误删 system 与新消息 → `test_first_turn_keeps_system_and_user`（Task 5）
2. **超长单条消息**（> 总预算）：保底保留最新 user + warning 日志，不抛异常不静默丢 → `test_single_message_over_budget_fallback`（Task 5）
3. **流中断**：astream 中途异常，已推 token 后仍发 error 事件 + `[DONE]`，不 500 → `test_stream_error_midway_emits_error_event`（Task 7）
4. **混合诉求**（"既退货又要开发票"）：complaint_type 判主诉求——schema Literal 兜底非法值（Task 8）+ 评估集含 3 条混合样例（Task 9）
5. **陌生 session_id**：自动建会话不报错 → `test_unknown_session_id_creates_conversation`（Task 7）
